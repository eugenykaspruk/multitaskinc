# Multitask Inc

This is a simple Telegram bot that allows users to set reminders for events. The bot uses a Google Sheet for data storage.

## Future Features

Here are some ideas for future enhancements:

*   **Recurring Reminders:** Allow users to set reminders that repeat on a daily, weekly, or monthly basis.
*   **Timezone Support:** Allow users to set their timezone so that reminders are sent at the correct time.
*   **Interactive Buttons:** Use Telegram's interactive buttons to make the user interface more intuitive.
*   **Natural Language Processing:** Use a natural language processing library to allow users to set reminders using natural language (e.g., "remind me to buy milk tomorrow at 5pm").
*   **Email Notifications:** Allow users to receive reminders via email in addition to Telegram.
*   **Calendar Integration:** Allow users to sync their reminders with their Google Calendar.
